# Enterprise Schema Exploration & Domain Identification
# Query Model Log Analysis and SQL Validation

An end-to-end data engineering and analytical pipeline designed to profile enterprise database schemas, evaluate semantic domain overlap using vector embeddings, and automate audit processing for text-to-SQL execution logs.

## 📌 Project Overview

### Scope & Overview: 
Conducted a structural and semantic analysis across 10 core target database tables.
### Structural Profiling: 
Evaluated table characteristics, data completeness, column metadata, data type distributions, and relational integrity via primary and foreign keys.
### Relational Connectivity: 
Confirmed a well-connected relational database structure, enabling clear navigation across primary entities and tables.
### Business Domain Mapping: 
Categorized tables into functional business domains to establish high-level operational context.
### Semantic Vector Overlap: 
Used embedding-based cosine similarity to reveal strong semantic overlap across business domains, showing they operate as an interconnected data model rather than isolated silos.
### Baseline Reference: 
Provides a clean foundational reference for data engineers and analysts to guide future schema discovery, data modeling, and pipeline integration.
